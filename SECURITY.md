# Security Policy

## Supported versions

Only the latest commit on `main` is supported.

## Reporting a vulnerability

**Do not open a public issue.**

Report privately through GitHub's *Report a vulnerability* button on the
Security tab, or email **nagizaazs@gmail.com** with:

- a description and the impact,
- steps or a script to reproduce,
- the affected commit or version.

You will get an acknowledgement within **48 hours**. Confirmed issues get a fix
or mitigation plan, and credit if you want it.
